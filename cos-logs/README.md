# cos-logs

本目录用于记录 **硬编码修改** 的日志，便于与上游仓库同步时排查差异。

## 策略说明

- **允许硬编码整改**：为加速原型开发，不再严格遵守“仅从源仓库同步”的限制。
- 对 Raven 项目内容可进行硬编码修改（含翻译、文案、UI 等）。
- 重要修改请在本目录下以日期或主题为文件名记录变更摘要，便于后续合并与审查。

## 日志文件命名建议

- `YYYY-MM-DD-简短描述.md`
- 或 `hardcode-翻译.md`、`hardcode-UI.md` 等按类型归档

## 示例记录格式

```markdown
## 日期
- **文件**: 路径
- **修改**: 简要说明
- **原因**: 原型/翻译/体验优化等
```
